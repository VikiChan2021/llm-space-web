# LLM Space 设计合作伙伴试点包

这是一套不需要部署的主持式试点材料，用于验证企业用户能否理解并完成“恢复试点—人工评审—质量门禁—晋升—第二轮”闭环。

## 本轮不验证什么

- 不验证公网自助注册、安装或部署。
- 不收集真实客户数据、内部政策、账号、密钥或个人信息。
- 不宣称已经获得商业验证；只有真实外部参与者的结果才计入北极星指标。

## 目标样本

招募 3 名设计合作伙伴，建议分别来自：

1. 电商或硬件售后负责人。
2. SaaS 客服或知识库负责人。
3. AI 交付顾问或企业自动化负责人。

参与者应对客服质量、知识库或 AI 回答发布有实际影响力，而不只是对 AI 工具好奇。

## 北极星指标

- 3 名外部设计合作伙伴完成首轮主持式试点。
- 至少 2 名在 3 分钟内恢复试点，并在 10 分钟内完成 10 条评审。
- 至少 2 名在 14 天内愿意用同一 Case Set 完成第二轮回归。
- 至少 1 名愿意付费，或明确承诺延长试点。

## 执行顺序

1. 主持人先阅读 `moderator-script.md` 并打开本地工作台。
2. 发送 `invitation-message.md` 中的邀请文案，不要承诺未填写的谢礼。
3. 开始前让参与者阅读 `privacy-and-consent.md` 和 `participant-guide.md`。
4. 参与者通过屏幕共享远程控制或同机浏览器亲自操作；主持人不代点。
5. 每场结束后立即填写 `session-scorecard.md`，只记录脱敏指标。
6. 完成 3 场后，按 `decision-rules.md` 选择下一个产品循环。

## 交付边界

当前使用本地 `http://localhost:15175/llm-space-web/#/workbench`。由于本轮未获得部署批准，参与者不能在自己的电脑上直接访问该地址。这是主持式可用性与需求验证，不是公网自助体验。
