## Dialog 可达性与上下文

- 在用户已经关闭常驻助手的状态下，Variables 与设置 Dialog 仍显示对应 Launcher 和确定性简短提示。
- Variables Launcher 位于同一个 Dialog 内容/焦点边界；点击后原 Variables Dialog 保持打开，助手输入框可见且可操作。
- Variables 状态只暴露 `variables` surface ID；助手明确提示“不读取表单值或正文”。
- Assistant 自己的 Run 确认 Dialog 从 surface 观察中排除，避免递归搬移助手或绕过确认。
