## 左侧：定义 Agent

左侧决定“这次运行要用什么”。

- **Models**：当前 Thread 使用的智谱模型和温度、最大输出、思考模式等参数。
- **Tools**：允许模型调用的工具。工具出现在列表中，不代表它一定会自动执行。
- **Variables**：向提示词注入当前日期等动态信息。
- **System prompt**：规定助手身份、行为边界、输出风格和工具使用要求。

修改会自动保存到当前浏览器的 Thread。

## 右侧：观察运行过程

右侧是消息和执行轨迹。你可以编辑用户消息、查看模型思考、Tool Call、工具 Response 和最终回答。流式输出期间不要切换 Thread；停止后，已生成内容仍会保留。

## 顶部：管理工作区

- **Threads**：新建、重命名、复制、导入、导出和删除 Thread。
- **重置示例**：确认后把当前 Thread 替换成天气工具示例。
- **设置**：外观、默认模型和 MCP 设置。
- **使用说明**：在新标签页打开本文档。

## 运行历史与撤销

工作台工具栏中的历史图标用于查看 Run 历史；撤销和重做用于恢复编辑状态。两者用途不同：历史回答“模型运行过什么”，撤销回答“Thread 配置改过什么”。

## 浏览器刷新后

Thread、运行记录、虚拟文件和多数偏好会从浏览器存储恢复。清理站点数据、使用隐私窗口或更换浏览器后，这些数据可能消失；重要 Thread 请及时导出 JSON。
