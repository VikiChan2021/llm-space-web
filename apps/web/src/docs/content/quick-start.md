## 30 秒完成第一次天气工具 Run

打开 Web 工作台后，你会看到一条已经填写好的用户消息：**搜索一下广州今天的天气**。左侧 Tools 已经预装天气、网页搜索和网页读取工具。

1. 保持默认的 `GLM-4.5-Air（推荐）`。
2. 点击右上角 **Run**。
3. 第一次运行时选择 **完整运行（推荐）**。工作台只在本次 Run 中启用 ReAct，自动执行游客白名单里的安全工具。
4. 模型会调用 `weather_report`、`web_search` 或 `web_fetch`，读取工具结果并整理最终答案。
5. 完成后点击 **查看运行记录**，检查模型、Tool Call、工具结果和 Run 快照。

如果你想逐步检查每次工具调用，可在第一次运行时选择 **逐步调试**：模型发起 Tool Call 后会暂停，由你确认结果并再次运行。这个一次性选择不会修改桌面端或浏览器的全局 Run 设置。

> 天气属于实时信息。应以工具返回的数据为准，不要只相信模型记忆中的结果。

## 你刚刚体验了什么

这不是普通聊天。一次完整流程可能包含：用户问题 → 模型判断 → Tool Call → 工具结果 → 模型回答。右侧消息区会保留每一步，便于检查模型为什么得到这个答案。

## 遇到错误怎么办

模型繁忙或当前账号无法使用某个模型时，工作台会保留 Thread，并提示你在 **Models** 中切换其他智谱模型后重试。免费额度耗尽、输入过长和并发限制会显示不同的恢复说明。
