## 30 秒完成第一次天气工具 Run

打开 Web 工作台后，你会看到一条已经填写好的用户消息：**搜索一下广州今天的天气**。左侧 Tools 已经预装天气、网页搜索和网页读取工具。

1. 保持默认的 `GLM-4.7-Flash（推荐）`。
2. 点击右上角 **Run**。
3. 模型会决定调用 `weather_report`、`web_search` 或 `web_fetch`。
4. 如果工具没有自动执行，检查调用参数后点击工具卡片中的执行按钮，再次点击 **Run** 让模型整理答案。

> 天气属于实时信息。应以工具返回的数据为准，不要只相信模型记忆中的结果。

## 你刚刚体验了什么

这不是普通聊天。一次完整流程可能包含：用户问题 → 模型判断 → Tool Call → 工具结果 → 模型回答。右侧消息区会保留每一步，便于检查模型为什么得到这个答案。

## 下一步

## 遇到错误怎么办

模型繁忙或当前账号无法使用某个模型时，工作台会保留 Thread，并提示你在 **Models** 中切换其他智谱模型后重试。免费额度耗尽、输入过长和并发限制会显示不同的恢复说明。
