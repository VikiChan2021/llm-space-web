## Auto run tools

开启后，工作台会自动执行明确标记为低风险的工具。天气、网页搜索、网页读取、只读虚拟文件和演示 MCP 可以自动运行；写入、Custom Tool、人工问题和未信任 MCP 会停下等待确认。

自动执行不是“所有工具无条件运行”。安全策略由 Web Host 决定，Thread 不能自行绕过。

## ReAct loop

ReAct 会在工具完成后自动发起下一轮模型调用，让模型读取结果、决定是否继续用工具，直到给出最终回答或触发上限。

典型流程：

```text
用户问题 → 模型 Tool Call → 自动执行工具
        → 模型读取结果 → 最终回答
```

## 游客上限

游客版最多自动进行 6 个模型回合、8 次工具调用，并有并发、时长和输出限制。每个模型回合都会消耗一次免费 Run。

## 推荐学习顺序

1. 先关闭两个开关，手动完成一次天气工具调用。
2. 只开启 Auto run tools，观察工具自动执行。
3. 再开启 ReAct loop，观察模型如何消费工具结果。
4. 打开运行历史，对比三次轨迹。

## 循环停止

重复调用、额度耗尽、达到回合上限或遇到需人工确认的工具时，循环会停止并保留已经生成的消息与结果。你可以调整提示词或工具参数后继续。
