## 数据保存在哪里

游客 Thread、虚拟文件、主题、默认模型和运行偏好主要保存在当前浏览器。刷新页面后会恢复，但它不是云端账户同步。

以下操作可能导致数据消失：清理站点数据、浏览器隐私模式结束、更换浏览器或设备、浏览器存储被策略禁用。

## 导入与导出

打开顶部 **Threads**：

- 导出会下载当前 Thread JSON。
- 导入会创建一个新 Thread，不覆盖已有记录。
- 导入的工具定义会保留，但只有游客 Host 支持且符合安全策略的工具可以执行。

重要 Thread 应定期导出。导出文件可能包含提示词、消息和工具参数，请像对待项目资料一样保管。

## 游客安全边界

- 服务器端智谱 Key 不会下发到浏览器。
- 客户端只能选择服务端白名单中的模型。
- 浏览器虚拟文件不能访问用户真实磁盘或腾讯云宿主文件。
- Bash、stdio MCP 和 Generator 等需要独立沙箱的能力不会在公共宿主进程中运行。
- 公共远程 MCP 在缺少网络层出站隔离时保持关闭。
- 错误响应不会返回认证头、上游原文或服务器堆栈。

## 当前暂未开放

GitHub 登录、BYOK、团队 Tenant、云端 Thread 同步、账单、隔离 Bash、stdio MCP 和 Generator 不属于当前游客 Hosted Alpha。界面中的部分入口会保留，用来说明能力边界和后续方向。

## 保护自己的信息

不要在公共游客 Thread 中提交密码、API Key、身份证件、未公开业务数据或任何不希望发送给模型服务的信息。工具访问外部网页或 MCP 时，相应参数可能发送给外部服务。
