## 停止一次运行

模型正在输出时，Run 按钮会变成停止操作。停止不会删除 Thread，已生成的部分内容会保留。重新运行会从原始用户消息重新开始，避免把不完整助手消息当作可靠上下文。

## 错误结果条

失败后页面会显示持久结果条，而不是只出现一闪而过的 Toast。它包含用户可理解的原因、是否允许重新运行，以及经过脱敏的错误码、HTTP 状态和本站请求编号。

## 常见错误

| 类型 | 建议 |
| --- | --- |
| 当前模型不可用 | 在 Models 中切换其他智谱模型后重试 |
| 今日免费额度已用完 | 等待页面显示的重置时间；BYOK 尚未开放 |
| 运行请求过于频繁 | 等待当前 Run 结束或稍后重试 |
| Thread 内容过长 | 删除无关消息或缩短提示词 |
| 网络连接失败 | 检查网络并重新运行 |

## 运行历史

工作台工具栏的历史图标会展示成功 Run。失败和主动停止不会伪装成成功记录；当前消息与错误结果条仍会保留，便于修复后重试。

## 提交问题时

可以附上本站请求编号、错误码、所选模型和复现步骤。不要提交 API Key、Cookie、浏览器完整站点数据或包含隐私的 Thread JSON。
