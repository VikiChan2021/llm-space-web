## 可选模型范围

游客工作台只开放服务器配置的免费模型白名单：硅基流动的 `Qwen/Qwen3-8B`、OpenRouter 的 `openrouter/free` 和 `qwen/qwen3.8-27b:free`。当前这些入口仅支持文本，不支持图片、视频或音频。

新访客默认使用硅基流动的 `Qwen/Qwen3-8B`。OpenRouter 免费自动路由的实际模型可能变化；做前后对比时，应选择固定模型并保持模型和参数一致。

## 切换当前 Thread 的模型

点击左侧 **Models** 当前模型名称，搜索并选择另一个可用的免费模型。选择会保存到当前 Thread，不影响其他 Thread。旧 Thread 若仍使用已停止开放的 GLM 模型，请在这里手动切换；历史内容不会被改写。

## 设置新 Thread 的默认模型

点击顶部 **设置 → 模型**，选择新 Thread 默认模型。此设置只影响以后新建或重置的 Thread；已有 Thread 不会被静默改写。

## 免费额度如何计算

页面顶部显示当前浏览器当天剩余的免费 Run。每一次模型回合都会消耗一次，包括 ReAct 为了读取工具结果而发起的后续模型回合。工具调用还有独立的安全与次数限制。

本站额度与供应商账号额度分开计算。OpenRouter 免费额度由公共服务器账号共享；本站显示还有 Run，并不保证供应商仍有额度。免费模型也可能限流或暂时缺少容量。

## 某个模型不可用

模型可能因为供应商额度、速率限制或上游繁忙而失败。遇到“当前模型暂不可用”时：

1. 打开左侧 **Models**。
2. 在硅基流动与 OpenRouter 的免费模型之间手动切换。
3. 点击错误结果条中的重新运行。

工作台不会在后台悄悄换模型，避免你误判实际测试对象。
