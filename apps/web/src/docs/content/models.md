## 可选模型范围

游客工作台开放智谱官方当前列出的文本与推理模型，包括 Flash、GLM-4.5/4.6/4.7 和 GLM-5 系列。图片生成、视频、Embedding、音频和 OCR 使用不同接口，因此不会出现在当前 Thread 模型选择器中。

默认使用 `glm-4.7-flash`。它适合首次体验和工具调用，也能降低公共体验成本。

## 切换当前 Thread 的模型

点击左侧 **Models** 当前模型名称，搜索并选择另一个智谱模型。选择会保存到当前 Thread，不影响其他 Thread。

## 设置新 Thread 的默认模型

点击顶部 **设置 → 模型**，选择新 Thread 默认模型。此设置只影响以后新建或重置的 Thread；已有 Thread 不会被静默改写。

## 免费额度如何计算

页面顶部显示当前浏览器当天剩余的免费 Run。每一次模型回合都会消耗一次，包括 ReAct 为了读取工具结果而发起的后续模型回合。工具调用还有独立的安全与次数限制。

## 某个模型不可用

模型可能因为智谱账号权限、余额、速率限制或上游繁忙而失败。遇到“当前模型暂不可用”时：

1. 打开左侧 **Models**。
2. 优先切换到 `GLM-4.7-Flash（推荐）` 或另一种 Flash 模型。
3. 点击错误结果条中的重新运行。

工作台不会在后台悄悄换模型，避免你误判实际测试对象。
